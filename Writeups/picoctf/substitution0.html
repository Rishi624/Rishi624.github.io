// Given Challenge

    A message has come in but it seems to be all scrambled. Luckily it seems to have the key at the beginning. Can you crack this substitution cipher? Download the message here

At first glance the paragraph looked completely unreadable, but the according to the flag format the text ruseSWX was meant to be replaced with picoCTF using the mapping shown in the challenge.

r → p u → i s → c e → o S → C W → T X → F

After applying those replacements, ruseSWX became picoCTF. This confirmed that the challenge was based on a simple substitution cipher.

// Finding the Mapping

The next clue was the 26-letter string:

ZGSOCXPQUYHMILERVTBWNAFJDK

This is a rearranged alphabet. Each letter maps to the normal alphabet in order.

Cipher ZGSOCXPQUYHMI
Plain ABCDEFGHIJKLM

Using this mapping, I decoded the first word:

Qctcnrel ↓ Hereupon

Since the output was valid English, I knew the mapping direction was correct. I repeated the same process for the remaining text until the entire paragraph became readable.

// Decoding the Flag

The encrypted flag was:

ruseSWX{5NG5717N710L_3A0MN710L_357GX9XX}

The prefix was known as picoCTF

ruseSWX → picoCTF

Then I applied the substitution table to every remaining character inside the braces. The decoded text became:

picoCTF{5UB5717U710N_3V0LU710N_357BF9FF}

// The Result

The final flag is:

picoCTF{5UB5717U710N_3V0LU710N_357BF9FF}
